# More-Ways-to-Die-MWtD-Minecraft
This mod adds more unique ways to die, with the goal to make your day to day minecraft experience more challenging.

## Installation
This mod is made for Minecraft 1.21.x and requires NeoForge.

1. Install the correct version of NeoForge for Minecraft 1.21.x from the official NeoForge website or launcher.
2. Start Minecraft with the NeoForge profile at least once so the game creates the required files and folders.
3. Download the latest release of this mod as a `.jar` file from the Releases page.
4. Open your Minecraft game directory:
   - Windows: `%APPDATA%\.minecraft`
   - macOS: `~/Library/Application Support/minecraft`
   - Linux: `~/.minecraft`
5. Go to the `mods` folder inside that directory. If it does not exist, create it.
6. Copy the downloaded mod `.jar` file into the `mods` folder.
7. Launch Minecraft using the NeoForge profile for 1.21.x.

The mod will load automatically when you start the game with NeoForge installed and the `.jar` file in the `mods` folder.
